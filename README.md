# Intranet Caminos

Intranet del equipo de Caminos: pase de jornada, malla de horarios, comunicados, asistencia, informes, solicitudes y accesos al Gestor de reservas, Caminos Documentos y el Cotizador.

- **Sitio:** `index.html` (GitHub Pages, rama `main`, carpeta raíz). Mientras `assets/config.js` no tenga el proyecto de Supabase, la página muestra «La intranet se está preparando» con un enlace a la demostración.
- **Demostración:** `pruebas/demo.html`, con datos de ejemplo que no se guardan.
- **Documentación completa, pendientes y puesta en marcha:** [LEEME.md](LEEME.md).
